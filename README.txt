FixRed Nokos — situs statis
============================

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser untuk menguji tampilan.
3. Agar publik di internet, unggah index.html ke repositori GitHub.
4. Buka Settings > Pages pada repositori.
5. Pada Build and deployment pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses publikasi selesai; GitHub Pages akan menampilkan alamat situs.

Catatan:
- Situs ini statis, tidak membutuhkan server, database, API key, atau file .env.
- File tidak mengumpulkan nomor telepon, OTP, PIN, atau data pengunjung.
- Saya tidak dapat menerbitkan ke akun GitHub/hosting milik Anda tanpa akses dan tindakan dari akun Anda.
- Ini panduan independen, bukan produk resmi WhatsApp; tidak bisa membuka blokir atau menjamin pendaftaran berhasil.
